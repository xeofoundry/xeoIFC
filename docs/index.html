About xeoIFC demo viewer

This demo viewer showcases xeoIFC in the browser. It loads IFC models locally with WebAssembly and renders them with WebGPU.

No IFC model information is uploaded or stored server side by this viewer. All IFC data is processed in the client web browser.

This demo viewer has restrictions regarding the file size, because it runs in WebAssembly.

xeoIFC as native converter application does not have such restrictions, and converts any IFC file: IFC2X3, IFC4 or newer.
