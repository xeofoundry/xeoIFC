                About xeoIFC Web

                xeoIFC Web is the demo viewer of the xeoIFC WebAssembly library. It loads IFC models locally with WebAssembly and renders them with WebGPU.

                No IFC model information is uploaded or stored server side by this viewer. All IFC data is processed in the client web browser.

                XeoIFC converts any IFC file: IFC2X3, IFC4 or newer, same as the native xeoIFC converter application/API library.

                Federated models: With drag&drop, several files can be loaded and appended to previously loaded models.

                Merge feature: Several loaded models can be merged into a new IFC file using the "Export" button.

                Split feature: When one or more elements are selected (via tree view or 3D view), that subset of elements can be exported to a new IFC file using the "Export" button.

                Repository: www.github.com/xeofoundry/xeoIFC

                Source code: xeoIFC Web is open source under the MIT licence: xeoifc-web-source.zip, with the prebuilt xeoIFC WebAssembly library, on the releases page.
