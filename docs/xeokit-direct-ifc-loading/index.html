xeokit + xeoIFC WebAssembly

The xeoIFC engine runs as a WebAssembly module in a Web Worker, parses and tessellates the IFC or STEP CAD file and hands one packed geometry buffer plus an object tree to a xeokit SceneModel and MetaModel. No conversion step, no server, no upload.

Click an object for its property sets. See also the xeoIFC WebGPU viewer.
